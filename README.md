# Organização Acadêmica

Projeto escolar de Java para a disciplina de Programação e Sistemas Computacionais.

## Objetivo

Este projeto simula uma aplicação para ajudar estudantes a organizar:

- disciplinas
- atividades
- prazos de entrega
- provas
- rotina acadêmica

A solução usa conceitos de orientação a objetos, encapsulamento, herança e polimorfismo em Java.

## Estrutura

- `src/main/java/com/academica/app` – aplicação principal
- `src/main/java/com/academica/model` – classes do domínio

## Como executar

```bash
mvn package
java -cp target/classes com.academica.app.Main
```

## Conceitos aplicados

- classes e objetos
- encapsulamento
- herança
- polimorfismo
- listas e organização de dados
- uso de datas e planejamento acadêmico

## Exemplo de funcionamento

A aplicação cria um estudante, adiciona disciplinas e agenda tarefas com diferentes níveis de urgência.
